### Requirement: PERF-07a Typical host sizes
The PERF-07 comparison SHALL include fixtures of 50, 200 and 500 nodes with orthogonal
connections, and the recorded result SHALL name the browser, device pixel ratio and date
(PERF-07).

#### Scenario: Typical-size report
- **WHEN** the comparison runs on the three fixtures
- **THEN** the report lists per-workload results for both libraries
